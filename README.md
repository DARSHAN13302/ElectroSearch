# ElectroSearch - Open Electronics Reference Platform 
 
An open engineering reference and discovery platform that connects electronics problems, engineering knowledge, tools, components, suppliers, standards, research, manufacturing resources and career opportunities in one searchable ecosystem. 
 
## Features 
- ?? Unified search across 9+ categories (Tools, Components, News, Jobs, etc.) 
- ?? Live news ticker with industry updates 
- ?? Simulation Tool Finder (guided discovery) 
- ?? Engineering Problem Solver (troubleshooting assistant) 
- ? Favorites saved in your browser 
- ?? Dark / Light theme toggle 
- ?? Fully responsive (mobile, tablet, desktop)
